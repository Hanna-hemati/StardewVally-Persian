# Farsi Mod 2 — فارسی‌ساز استاردیو ولی (نسخهٔ ۲)

این مود متن‌های بازی **Stardew Valley** را به فارسی ترجمه می‌کند، فونت فارسی و چیدمان راست‌به‌چپ را هم به بازی اضافه می‌کند و زبان **فارسی** را به منوی انتخاب زبان بازی می‌افزاید.

> مستقل از مود قبلی (PersianValley) است و بدون تداخل کنار آن نصب می‌ماند — شناسهٔ مود، کد زبان (`fa-IR-v2`)، فونت‌ها و همهٔ فایل‌ها مخصوص خودش است؛ هر دو می‌توانند هم‌زمان نصب باشند و هر کدام را خواستید حذف یا فعال کنید.

> وضعیت: متن‌های اصلی با Gemini 4 Argon بازبینی شده‌اند (۱۱٬۰۶۱ رشته)، و ۳٬۲۹۶ خط دیالوگ در ۵۲ فایل شخصیت با لحن مخصوص هر شخصیت بازنویسی شده‌اند. راست‌چینی، شکستن صحیح خطوط فارسی و انیمیشن تایپ هم فعال است. بخش‌های ساختاری (رویدادها، نامه‌ها و داده‌های فنی) برای حفظ ساختار بازی با ترجمهٔ قبلی نگه داشته شده‌اند.

## نیازمندی‌ها

- Stardew Valley نسخهٔ **1.6.x**
- **SMAPI 4.x**

## نصب

1. اگر SMAPI نصب نیست، از [smapi.io](https://smapi.io) نصبش کنید.
2. پوشهٔ `FarsiMod2` را داخل پوشهٔ `Mods` بازی کپی کنید:
   - مک: `Stardew Valley.app/Contents/MacOS/Mods/FarsiMod2`
   - ویندوز: `Stardew Valley/Mods/FarsiMod2`
3. بازی را **با SMAPI** اجرا کنید.
4. در صفحهٔ عنوان، دکمهٔ زبان (گفتگو در پایین-راست) را بزنید و **فارسی** را انتخاب کنید. اگر مود فارسی دیگری هم نصب باشد دو دکمهٔ فارسی می‌بینید؛ این مود دکمهٔ سبز با برچسب «فارسی» است.
5. برای اعمال کامل همهٔ متن‌ها، بازی را یک‌بار ببندید و دوباره باز کنید.

> نسخهٔ آمادهٔ نصب در `dist/FarsiMod2.zip` قرار دارد. برای ساخت از سورس، `./build.sh` را اجرا کنید (نیازمند Python 3 و .NET 6 SDK است).

## چه چیزهایی ترجمه شده‌است؟

- رابط کاربری، منوها، تنظیمات، پیام‌ها و اعلان‌ها
- نام و توضیح آیتم‌ها، ابزارها، سلاح‌ها، لباس‌ها، ماهی‌ها و هیولاها
- دیالوگ‌های NPCها (شامل دیالوگ‌های ازدواج و گزینه‌های گفتگو)
- رویدادها (Events)، جشنواره‌ها، نامه‌ها، تلویزیون، مأموریت‌ها و یادداشت‌های مخفی
- نام مکان‌ها و متن‌های روی نقشه
- تاریخ، روزها، فصل‌ها و قالب ساعت درون‌بازی

## چه فرقی با نسخهٔ قبلی (PersianValley) دارد؟

- متن‌های اصلی با **Gemini 4 Argon** بازبینی شده‌اند (بیش از ۱۱٬۰۰۰ رشته).
- انیمیشن تایپ راست‌به‌چپ و راست‌چین‌شدن دیالوگ‌ها فعال است؛ متن با صدای تایپ و به‌صورت حرف‌به‌حرف از راست به چپ ظاهر می‌شود.

- **متنِ تایپ‌شدهٔ بازیکن هم درست نمایش داده می‌شود:** اسم مزرعه، بازیکن و حیوانات در زمان بازی حروفشان به هم متصل و راست‌چین می‌شود (موتور `FarsiText.cs`)، و اندازه‌گیری عرض (`SpriteFont.MeasureString`) هم متن شکل‌دهی‌شده را می‌بیند.
- ترجمه‌ها با پیپ‌لاین جدید ساخته شده‌اند: ۱۷۹ asset و بیش از ۱۳٬۰۰۰ رشته.
- کد زبان مستقل (`fa-IR-v2`) تا با مودهای فارسی دیگر تعارض پیش نیاید.
- لحن شخصیت‌ها (جرج غرغرو، ابیگیل بازیگوش، الیوت ادبی، پم بی‌پرده و…) جداگانه بازبینی شده است.
- تولتیپ‌ها و متن‌های چندباره‌رسم (سایه/دورخط) دیگر دوبار راست‌به‌چپ نمی‌شوند.
- فونت‌ها تازه ساخته شده‌اند: Vazirmatn + Noto Sans Symbols، ۱٬۲۵۰ نویسه در هر سه فونت (دو SpriteFont و یک BMFont).

## محدودیت‌های شناخته‌شده

- بعضی نوشته‌های داخل تصویرها (مثل دکمه‌های NEW/LOAD/CO-OP/EXIT صفحهٔ عنوان) تصویر هستند، نه متن؛ انگلیسی می‌مانند.
- ترجمهٔ ماشینی است؛ ممکن است بعضی نام‌ها یا اصطلاح‌ها طبیعی نباشند.
- ترجمهٔ مودهای دیگر تحت پوشش نیست.

## ساختار پروژه

```
FarsiMod2/                 مود (سورس + asset آمادهٔ نصب)
  ModEntry.cs              ثبت زبان، بارگذاری ترجمه‌ها و پچ متن‌کشی بازی
  FarsiText.cs             موتور شکل‌دهی اتصالی و راست‌به‌چپ متنِ تایپی بازیکن
  assets/fonts/            فونت‌های ساخته‌شده
  assets/translations/     ترجمه‌های آمادهٔ نمایش (شکل‌دهی‌شده)
  manifest.json
tools/
  fontgen/                 ساخت فونت‌ها و دکمهٔ زبان از TTF
  translations/            پیپ‌لاین ترجمه و شکل‌دهی
dump/                      متن‌های انگلیسی استخراج‌شده از فایل‌های بازی (مرجع)
translations/              ترجمه‌های فارسی منطقی (قابل ویرایش) + ترجمه‌های دستی
dist/                      نسخهٔ آمادهٔ نصب و فایل zip
```

## ویرایش ترجمه

1. فایل موردنظر را در `translations/fa` باز کنید (مثلاً `Strings__UI.json`).
2. مقادیر را به فارسی طبیعی تغییر دهید. این‌ها را دست نزنید:
   - `{0}`، `{1}` و … (جای‌نگه‌دارها)
   - `$s`، `#$b#`، `%item ...`، `@`، `^`، `%%` و بقیهٔ دستورهای بازی
   - بخش‌های بین دو آندرلاین در پاسخ‌های `$y` (شناسهٔ داخلی است)
3. بعد از ویرایش:

```bash
python3 tools/translations/pipeline.py     # شکل‌دهی و ساخت assetهای مود
( cd FarsiMod2 && dotnet build -c Release )
# پوشهٔ FarsiMod2/bin را داخل Mods بازی جایگزین کنید
```
